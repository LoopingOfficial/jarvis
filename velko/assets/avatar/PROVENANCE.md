# VELKO anatomical avatar

Source is this workspace's `ui/assets/avatar/jarvis_v2_3_high.glb`, generated by its MPFB-based pipeline (`jarvis/blender_scripts/avatar_engine_v2_job.py`). The anatomical mesh is MakeHuman/MPFB, with the project's existing rig, facial details and skin textures. The corrective build script replaces the detached primitive clothing, builds separate weighted jacket and trouser shells from welded anatomical topology, relaxes the skin contours into fabric, adds thickness, a stand collar, ribbed cuffs, shaped trainers, a fitted scalp and swept chestnut hair strands. Blue seams and embroidery are authored geometry. The original deformation bone names and skin weights are preserved.

MakeHuman core visual assets are CC0: https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md . Project-created styling is retained within the user's existing project. No downloaded third-party character has been introduced. Original input remains untouched.

This is an anatomical game character, **not a photoreal scan or a match to the supplied portrait**. Hair, cloth and facial shading still need professional asset work for the target reference quality. `inspection.png` is the actual Blender rendering, not a reference image or marketing composite.

Rebuild: Blender 4.2+ --background --python velko/scripts/build_premium_avatar.py . Runtime uses the continuous skinned rig and two-bone arm/leg solving against world-space targets.
